# Сцены и режимы отображения

В LoreForge `Location` остаётся контейнером мира, а `Scene` описывает конкретную игровую поверхность внутри локации.

Пример:

- `Аптека Морриса` — локация;
- `Торговый зал`, `Склад`, `Тайная комната` — сцены внутри локации.

## Режимы сцены

У сцены есть `presentation_mode`:

- `tactical_map` — тактическая карта для VTT: токены, fog of war, vision и GM-инструменты работают поверх изображения;
- `illustration` — атмосферная иллюстрация или вид сцены: изображение становится главным объектом экрана, а токены и туман скрываются, чтобы не мешать восприятию.

В UI эти значения показываются как:

- `tactical_map` → **Тактическая карта**;
- `illustration` → **Иллюстрация / вид сцены**.

## Отображение изображения

Поле `image_fit` управляет тем, как показывается картинка сцены:

- `contain` → **Вписать полностью**;
- `cover` → **Заполнить область**.

`contain` полезен для карт, где важно видеть всю сетку или план. `cover` лучше подходит для атмосферных иллюстраций.

## Scene Manager

ГМ может:

- создать сцену внутри локации;
- выбрать режим сцены;
- выбрать отображение картинки;
- загрузить карту или иллюстрацию;
- переключить активную сцену;
- переместить игрока на сцену.

Игроки и наблюдатели видят только доступные сцены без GM-инструментов.

## Ограничения

- В режиме `illustration` токены и fog of war скрываются на frontend-слое.
- Это не удаляет данные токенов и vision из БД.
- Переключение режима не меняет права доступа к сцене.
